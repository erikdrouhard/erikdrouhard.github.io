# Verse Design System website assets

This directory contains the self-contained assets served by the published Verse Design System case study. Selected web-ready PNGs remain under `media/`; optimized derivatives of large source images and presentation slides live under `media/web/`.

The canonical original source belongs in the parent portfolio workspace under `case-study-assets/verse/`. Do not treat a compressed or resized website copy as the only copy of an irreplaceable source.

The website implementation must remain self-contained. Do not reference files outside the `website2026/` repository from HTML, CSS, or JavaScript.

The current originals were duplicated without modification to `case-study-assets/verse/images/verse-design-system/` on 2026-08-06. The website copies are deployable derivatives; the parent asset library is the provenance source of truth.
